# 🚀 Tech Event Finder

A Java-based desktop application that helps users discover technology events, search events based on different filters, register for events, and manage event information through an easy-to-use AWT graphical interface.

---

## 📌 Features

* 🔍 Search events by city
* 🏢 Search events by company
* 📅 Search events by date
* 📋 View all available tech events
* ✅ Register for events
* 👤 Store participant details
* 💾 Save and load event data using file handling
* 🖥️ Interactive Java AWT GUI
* 📊 Event statistics and management

---

## 🛠️ Technologies Used

* Java
* Java AWT
* Object-Oriented Programming (OOP)
* Event Handling
* File Handling

## 📂 Project Structure

```text
TechEventFinder/

│── FileManager.java
│── TechEventFinderGUI.java
```

---

## 📖 Class Description

### Event.java

Represents a technology event containing details such as:

* Event Name
* Company
* City
* Date
* Venue

### EventManager.java

Manages all event operations including:

* Adding events
* Searching events
* Displaying available events

### Registration.java

Handles participant registrations and stores registration information.

### User.java

Represents user details required for event registration.

### FileManager.java

Performs file operations such as saving and loading event information.

### TechEventFinderGUI.java

Provides the graphical user interface using Java AWT.

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/TechEventFinder.git
```

2. Open the project in VS Code or any Java IDE.

3. Compile all Java files.

```bash
javac *.java
```

4. Run the application.

```bash
java TechEventFinderGUI
```
